# CapCut Export Settings – TikTok + Shorts + Reels

Use these exact settings every time.

---

## Recommended Export

- **Resolution**: 1080x1920 (Full HD vertical)
- **Frame rate**: 30 fps
- **Bitrate**: High (or Recommended)
- **Format**: MP4
- **Codec**: H.264 (best compatibility)

---

## Platform Notes

| Platform | Notes |
|----------|-------|
| TikTok | 1080x1920, under 60s, this is your main platform |
| YouTube Shorts | Same file works perfectly |
| Instagram Reels | Same file, just upload |

---

## File Naming Convention

```
TrackName_Type_Date.mp4

Examples:
Alhamdulillah_Cinematic_2026-09-18.mp4
StillStanding_UGC_2026-09-18.mp4
Bismillah_Lyrics_2026-09-19.mp4
```

This keeps your content bank organized when you have 50+ videos.

---

## Final Checklist Before Export

- [ ] Audio is clear and not distorted
- [ ] Text is readable on a real phone screen
- [ ] End card has @planlifegrateful
- [ ] Duration is 15–25 seconds (sweet spot)
- [ ] No black frames or awkward cuts at the end
