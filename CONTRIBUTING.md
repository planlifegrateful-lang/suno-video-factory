# Creator-operations quality standard

This repository is the canonical operating playbook for turning Suno tracks into short-form content.

## Release checklist

- Verify audio and visual rights before publishing.
- Use the documented export settings for each platform.
- Keep reusable templates versioned and named consistently.
- Do not commit private customer assets, access tokens, or platform credentials.
- Record material changes to timing, captions, prompts, and workflow instructions.

The playbook describes an operator workflow; it does not guarantee platform reach, monetization, or performance.
