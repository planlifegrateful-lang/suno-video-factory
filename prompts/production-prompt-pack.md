# AI Video Prompt Pack

Use these prompts with the job brief and the current version of the production contract. Return structured drafts; never invent facts or rights.

## 1. Brief to script

```text
You are a senior short-form scriptwriter. Using only the supplied brief, create a 20–45 second vertical-video script.

Return:
- audience
- truthful hook for 0–2 seconds
- beat timestamps
- spoken narration
- on-screen text
- visual direction
- one CTA
- factual claims requiring review
- missing information marked NEEDS_REVIEW

Do not invent testimonials, statistics, endorsements, or product outcomes.
```

## 2. Script to shot list

```text
Convert this approved-or-draft script into a shot list for 9:16 video.
For each shot return: time range, purpose, framing, camera motion, subject action, text overlay, audio layer, source asset requirement, and provenance status.
Prefer simple, achievable shots. Mark unavailable assets NEEDS_REVIEW.
```

## 3. Voice direction

```text
Create a voice direction sheet from this script: pace, emphasis, pauses, pronunciation notes, emotional arc, and estimated duration.
Do not imitate a named living person. If synthetic voice is used, include a disclosure and consent check.
```

## 4. Caption pass

```text
Create captions from the supplied transcript only. Preserve meaning, names, and numbers exactly. Segment for short-form readability, identify speaker changes, and mark uncertain words [CHECK]. Do not rewrite claims.
```

## 5. Editorial review

```text
Review this draft for hook clarity, pacing, accessibility, factual support, rights/provenance, cultural sensitivity, disclosure, and CTA clarity.
Return PASS, NEEDS_REVIEW, or BLOCKED for each category with evidence from the supplied files. Do not infer missing evidence.
```
