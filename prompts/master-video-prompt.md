# Master Video Prompt – Suno → Scroll-Stopping Short

Copy-paste this into CapCut AI, Kling, Luma, or any text-to-video tool.

---

## Universal Prompt Template

```
Cinematic vertical 9:16 video, 15-30 seconds, Islamic motivational aesthetic.

Scene: Soft golden hour light, subtle green and gold tones, peaceful but powerful energy.
A young Muslim person (or silhouette) standing strong, looking toward the horizon / sky.
Gentle wind, soft particles of light, emotional and uplifting atmosphere.

Style: Photorealistic cinematic, shallow depth of field, film grain, high quality, 4K look.
Mood: Hopeful, grateful, resilient, spiritual strength.
Camera: Slow push-in or gentle orbit, smooth motion.
No text in the generated video. No logos.
```

## CapCut Manual Overlay Instructions

After generating the base video:

1. Add the Suno audio track (full or 15-30s clip of the hook)
2. Auto-captions ON (white text, bold, black outline)
3. Add one big emotional line at the start (0-3s):
   - "Alhamdulillah for this test"
   - "Ease is already written"
   - "I planned. Now I trust."
4. End with track name + @planlifegrateful
5. Export 1080x1920, high quality

Make 3 versions of every track:

- Version B: UGC style (you speaking / reacting)
- Version C: Lyrics on screen only (karaoke style)

Test which one the algorithm pushes hardest.
