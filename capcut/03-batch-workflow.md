# CapCut Batch Workflow – 5 to 10 Reels in One Session

This is how you scale without burning out.

---

## Preparation (10 minutes once)

1. Generate or select 5–10 Suno tracks (or the best 15–25s clips)
2. Generate matching background videos (use master prompt from `/prompts`)
3. Create one perfect CapCut master template (from `01-master-template.md`)
4. Save all text presets

---

## Batch Session (60–90 minutes)

### Round 1 – Audio + Video Drop (20 min)
For each track:
- Duplicate the master template
- Replace audio with Suno clip
- Replace background video
- Rough trim to 18–25 seconds
- Name the project: `TrackName_Date`

### Round 2 – Captions + Text (25 min)
For each project:
- Run Auto Captions
- Style captions once, then copy style to others
- Drop in Hook text + Peak emotional line from presets
- Adjust timing so text hits on the emotional peak of the audio

### Round 3 – End Cards + Polish (15 min)
- Add end card to all
- Quick color grade if needed (same preset for consistency)
- Check volume (audio should be clear, voice/text readable)

### Round 4 – Export (15 min)
- Use the exact export settings in `06-export-settings.md`
- Export all as 1080x1920
- Name files clearly: `Alhamdulillah_Reel_01.mp4`

---

## Daily vs Batch

- **Daily**: 1–2 Reels using the 15-min system
- **Batch day** (1–2x per week): 5–10 Reels using this workflow

This is how you stay consistent and still have a life.
