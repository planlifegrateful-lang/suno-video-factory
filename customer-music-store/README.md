# Customer Music Store — Preview

A phone-friendly customer catalog for the Ummah Anthems music projects.

## What works
- Search tracks and filter by theme.
- Add/remove individual songs.
- Select the full five-song collection.
- See the selected tracks and draft price calculation (temporary; refresh/close clears it).
- Responsive layout for mobile and desktop.

## Important launch gates
This repo documents five song projects, but the README says they are to be generated in Suno. The catalog therefore labels them as audio-pending. This page does not pretend that audio masters exist, does not collect money, and does not link to the unrelated Grateful Habit OS checkout.

Before launch:
1. Export and upload each final audio master.
2. Add verified preview URLs and secure delivery URLs.
3. Create/confirm the actual music checkout product(s).
4. Update the catalog with the live price and checkout destination.
5. Test a real purchase and customer download.

Draft pricing shown: $3 per individual song / $7 for the complete five-song collection. These are planning prices only, not live offers.

## Open
Open `index.html` in a browser, or serve this folder with any static web host.
