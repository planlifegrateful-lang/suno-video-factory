# 15-Minute Suno → Video System

Do this every day. No overthinking.

---

## Minute 0-2: Choose

- Open Suno → pick the track with the strongest hook today
- Or use the track you just generated

## Minute 2-5: Prompt

- Open `/prompts/master-video-prompt.md`
- Copy the base + the track-specific variation
- Paste into CapCut AI / Kling / Luma
- Generate 2-3 versions

## Minute 5-10: Edit

- Drop the best video into CapCut
- Add the Suno audio (trim to 15-25s of the best part)
- Auto captions
- Add 1-2 emotional text lines from the grateful language
- End card with @planlifegrateful

## Minute 10-13: Export & Title

- Export 1080x1920
- Write caption using this formula:

```
[Emotional hook in first line]

[1-2 sentences of value]

Track: [Name]
@planlifegrateful on Suno

#islamicmotivation #alhamdulillah #suno #muslimtiktok
```

## Minute 13-15: Post

- Post to TikTok first
- Then YouTube Shorts
- Then Instagram Reels
- Save the video in a folder named by date + track

---

## Weekly Review (Sunday 10 min)

Look at which videos got the most:
- Saves
- Shares
- Profile visits

Double the style that won. Kill the rest.
